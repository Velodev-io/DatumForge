# Retained training review cache

These files preserve the earlier local PDFKit extraction, contact sheets and
selected detailed page renders. The user confirmed on 22 October 2026 that the
original training PDFs were accidentally deleted. During that period, the original
files could not be rehashed or rerendered. They have since been restored and
verified; see the dated update below. This directory is research evidence; it is not a
reconstructed PDF collection or a complete set of detailed page images.

[cache-manifest.json](cache-manifest.json) records hashes of the retained files.
[The original review manifest](../solidworks-training-sources.json) records the
PDF hashes captured before deletion. A current cache hash does not revalidate an
original PDF hash. Each per-document JSON retains page-numbered text. Contact
sheets show an overview of all pages; only the named pages have detailed renders.
The extraction scripts describe the earlier method, and cannot recreate absent
PDFs by themselves.

Use this cache to continue independent implementation and review. If a diagram or
restriction cannot be established from these records, keep that coverage item
open until an authorized source or restored original resolves it. No source
restriction may be guessed from the intended implementation.

This is private, user-supplied research material. Do not include it in application
resources, installers, offline engineering catalogs or published documentation.
No permission to redistribute the training material is established here.

Update, 23 October 2026: the originals were restored to the same Downloads folder.
[Source revalidation](../../testing/artifacts/core-modeling/source-restoration-2026-10-23.json)
confirms that all eleven original PDF hashes match. The deletion/unavailability
described above records the cache's preservation history; it is no longer the
current source status. Retained cache files and their hashes remain unchanged.
