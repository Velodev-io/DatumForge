## Supported scope and remaining restrictions

- Planar hole placement with interior centers. Simple/counterbore/countersink/tapped
  cylinders use geometric terminations. Drill-point holes support Blind/ThroughAll;
  tapered/PipeTap sections support Blind. Unsupported combinations fail explicitly.
- Parallel ribs currently require a straight open chain. Normal ribs use exact
  open/closed thin sections. A direction that does not meet the target fails.
- Feature seeds transform their tools; they do not re-evaluate Up To Next at each
  new position. Body seeds use the selected producing stage. Output bodies remain
  within the ten-body admission. One-instance patterns are rejected as having no
  copies; no body/output identity is fabricated for a no-op.
- Linear variable-radius laws currently support two endpoints; Smooth supports
  ordered control points. Propagation off is explicitly unsupported.
- Closed-face repetition (R4) is resolved: face seeds are sewn into a valid closed solid tool body (`BRepBuilderAPI_Sewing` + `BRepBuilderAPI_MakeSolid`) with strict non-closed rejection, exposed via `patFaces` list widget in `FeaturePanel`, and verified in `cm6.review` (`closedFaceSeeds`).
- Exact face/full-round blends (R1) and admitted catalog datasets/pickers (CM9/R2) remain Blocked. No restricted full-round success or actual catalog standard validation is claimed.
- Cosmetic threads are sampled display rings on a resolved complete cylinder,
  with bounded density; exact solids/topology remain unchanged. Hole-owned thread
  metadata is retained; standalone cosmetic-thread authoring supplies the overlay.
- Existing experimental CM6 files whose saved provenance was generated by a faulty
  adapter may fail exact replay validation. Originals are never rewritten to hide
  that mismatch. No released CM6 file format or migration acceptance is claimed.
