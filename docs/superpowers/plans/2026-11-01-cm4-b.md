# CM4.b implementation plan

**Goal:** Exact worker-owned datums, associative sketch support and derived sketch
projection, integrated through the CM4.a graph and a read-only worker command.

**Spec:** [CM4.b contracts](../../decisions/core-modeling-cm4-supports.md).
**Architecture:** Qt-only support definitions; worker-only OCCT reference/datum/
projection/evaluation adapters; existing single writer and semantic collections.
**Execution:** In-session TDD on the dedicated review branch. No automatic
delegation. Keep current pinned build paths. Commit/push after scoped verification;
no merge or additional module scope.

## Constraints / review focus

Keep all admission caps, physical 8 GB baseline, SI semantics, existing schemas,
native desktop ownership and deferred gates. Storage tests use marked disposable
roots and refuse release paths. Focus on ambiguous topology, degenerate frame
construction, reversed finite curves, source/target dependency cycles, exact
projection collapse, generated identity collisions and stale/canceled previews.

then exercise compiled production interfaces. Test expectations are analytical,
not generated from the implementation under test.
