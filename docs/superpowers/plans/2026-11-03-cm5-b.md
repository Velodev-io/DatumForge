# CM5.b implementation plan

**Goal:** Evaluate versioned CM5 solid intents exactly in the existing worker.
**Spec:** [CM5.b engine](../../decisions/core-modeling-cm5-engine.md), building on
[CM5.a](../../decisions/core-modeling-cm5-intent.md).
**Execution:** In-session test-first work from the user's explicit CM5.b go-ahead;
no automatic delegation or duplicate dependency/worktree setup. Dedicated review
branch; no merge/force-push. Stop before CM5.c and Module 11.

## Files and tasks

1. **Exact profiles** — `geometry/occt/ModelingProfiles.hpp/.cpp` reconstructs
   selected/whole regions and thin sections; reuse shared legacy profile and
   validity helpers from `Part.hpp/.cpp`. Tests first in
   `tests/core_modeling/modeling_profiles.cpp`, registered as `cm5.profiles`.
2. **Exact extents and features** — `ModelingFeatures.hpp/.cpp` and
   `ModelingExtents.cpp` evaluate extrude, revolve, draft and Boolean publication.
   `evaluateModeling(SupportDefinition, QCborArray intents, SupportBuild, Control)`
   returns `SupportResult` with updated transient Part and evaluation order.
   Tests first in `modeling_features.cpp` for independent geometry equations,
   source updates, target/graph errors and unchanged inputs on failure.
3. **Read-only worker integration** — add optional intents to
   `ProjectStore::previewSupports` and PreviewModelSupports dispatch. Use the
   existing response/lifecycle/coalescing contract, without any durable mutation.
   Add real marked-root store/worker tests and stale/canceled-preview checks.
4. **Verification/evidence** — record red/green logs and final frozen-source
   build, enabled CTest, formatting, changed-source analysis, ownership/research/
   coverage/spec checks under `artifacts/core-modeling/cm5-b-20261103`. Preserve
   failed attempts and unsupported geometry boundaries. Register only supported
   engine evidence; exact gaps and CM5.c–e/full acceptance remain explicit.
   Commit/push the successfully verified review branch and verify the remote SHA.

Each task follows a failing test, minimal implementation and a passing check.
Review source/reference ownership, tolerance ceilings, exact cap provenance,
midplane/side signs, target-stage freshness and retained accepted state before
final completion claims. No production experiment shortcuts or approximate mesh
geometry; no native/platform/installed/physical-resource acceptance claim.
