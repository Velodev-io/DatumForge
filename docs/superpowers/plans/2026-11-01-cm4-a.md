# CM4.a implementation plan

**Goal:** Typed geometry references and one bounded dependency validator shared by
existing sketch and feature evaluation.

**Spec:** [CM4.a contracts](../../decisions/core-modeling-cm4-graph.md), implementing
[CM4.a](../../CORE_MODELING.md#cm4--datums-and-associative-sketch-support).

**Architecture:** Kernel-free Qt Core reference and graph types. Sketch adapters
expose member identities and Pierce edges; feature planning adds profile,
source/body-writer and expression edges. Existing collection encodings remain.

**Execution:** In-session TDD; no automatic delegation, merge or push. Use the
dedicated local review branch and existing pinned build. No worktree/dependency
duplication is needed for this task. Local commits are authorized but optional.

## Constraints and review focus

Preserve UI/display versus sole exact-worker ownership, the physical 8 GB baseline,
existing admission caps, schema compatibility and deferred 6.1b/6.4c/7.4c.
Stop before Module 11. Tests touching storage use marked disposable roots.
Pay particular attention to selector/role mismatch, same IDs across kinds,
history violations hidden behind unranked nodes, missing cross-sketch inputs,
and cache reuse after upstream reference changes.

## Tasks

1. **Typed references** — add `src/domain/GeometryReference.hpp/.cpp` and
   `tests/core_modeling/graph.cpp`; register `cm4.graph` in CMake. Test versioned
   CBOR input and invalid selectors first, then implement validation/encoding.
2. **Graph validator** — add `src/evaluation/Graph.hpp/.cpp` to a Qt Core library.
   `GraphNode` supplies id/kind/references/member roles; `Graph(nodes, history,
   document)` exposes `order()`, `dependencies(id)` and `descendants(id)`.
   Test mixed-kind order/closure, missing roles/members, duplicates, scope,
   cycles, history and bounds one behavior at a time before implementation.
3. **Production adapters** — add `src/sketch/Dependencies.hpp/.cpp`, move existing
   Pierce dependency ordering onto the shared validator, and use it from
   `src/evaluation/Plan`. Test real Plan source-sketch invalidation and unchanged
   branches, plus legacy regressions, before integrating. Preserve feature-only
   `Plan::nodes` and history-result formats. Carry transitive sketch hashes.
4. **Evidence** — build all targets, run all enabled CTests, pinned format and
   changed-source Clang analysis, ownership/coverage/spec checks. Record exact
   outcomes and source identity under `docs/testing/artifacts/core-modeling/cm4-a-20261101/`.
   Update CM4.a docs/status separately from the 22 unverified CM4 workflows.

Each task follows failing test → minimum implementation → green check. Retain
failure logs. Review the final diff against the contract in a separate pass.
